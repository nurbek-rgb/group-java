# Такси диспетчерлік жүйесі

Учебный MVP диспетчерской системы такси на Java. Программа принимает заказы, через несколько потоков выбирает ближайшего свободного водителя, рассчитывает цену и сохраняет результат в SQLite.

## Что уже работает

- водители, машины, пассажиры и координаты;
- очередь заказов `BlockingQueue`;
- несколько диспетчерских потоков через `ExecutorService`;
- защита водителя от двух одновременных заказов через `ReentrantLock`;
- обычная и повышенная цена (surge pricing);
- SQLite + JDBC + DAO;
- транзакция назначения водителя;
- отчёт через Stream API и экспорт в CSV;
- 10 JUnit-тестов, сгруппированных по трём модулям.

## Запуск в VS Code

Нужна Java 17 или новее и расширение **Extension Pack for Java**.

```powershell
.\mvnw.cmd clean test
.\mvnw.cmd exec:java
```

После запуска появятся:

- `taxi_dispatch.db` — локальная база SQLite;
- `reports/trips.csv` — отчёт о поездках.

SQLite-сервер отдельно устанавливать не нужно: база хранится в одном файле.

## Структура

```text
src/main/java/kz/edu/taxidispatch/TaxiDispatchSystem.java       основной код MVP
src/test/java/kz/edu/taxidispatch/TaxiDispatchSystemTest.java  10 тестов
pom.xml                                                        Maven и зависимости
DEFENSE_GUIDE.md                                               инструкция для защиты
```

Главный код специально собран в одном Java-файле, но внутри разделён на небольшие классы: модели, расчёт цены, DAO, диспетчер и отчёты.
